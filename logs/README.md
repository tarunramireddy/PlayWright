# Logs Directory

This directory contains application and test execution logs generated by the Winston logger.

## Files

- `combined.log` - All log levels (info, warn, error, debug)
- `error.log` - Error-level logs only

## Log Levels

- **error**: Error conditions
- **warn**: Warning conditions  
- **info**: Informational messages
- **debug**: Debug-level messages

## Configuration

Log levels and output can be configured via environment variables:

```bash
LOG_LEVEL=debug  # Set minimum log level
```

## Retention

Logs are automatically rotated and cleaned up based on configuration in the logger utility.
